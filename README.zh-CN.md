# 投资组合收益的因子回归分析

[English](README.md) · 概率统计课程项目 · 第 13 组

## 项目概览

小组研究投资组合月收益与六个市场及因子变量的关系，分别拟合普通最小二乘回归，检验斜率、比较拟合程度，并给出置信区间和预测区间。最终展示记载了 492 条观测。这是关于变量关联的课程分析，不是经过验证的投资策略或因果研究。

## 我的贡献

最终小组 PPT 的**第 3 题（第 17–23 页）**标明由王正旸讲解。这部分比较市场因子 X1 与盈利能力因子 RMW（X4），涵盖拟合关系、斜率检验、模型比较和 95% 区间示例。其他题目属于小组成果，不作为我的个人独立工作认领。
