# Factor Regression and Portfolio Returns

[简体中文](README.zh-CN.md) · Probability and Statistics course project · Group 13

## Project at a glance

We studied how a portfolio's monthly return relates to six market and factor variables. The group compared separate ordinary least squares regressions, tested slopes, compared model fit, and reported confidence and prediction intervals. The final presentation describes 492 observations. This is a course analysis of associations, not a validated investment strategy or causal study.

## My contribution

The final group presentation names Zhengyang Wang on **Problem 3 (slides 17–23)**. That section compares the market factor (X1) with the profitability factor RMW (X4): fitted relationships, slope tests, model fit, and a 95% interval example. Other numbered problems belong to the group presentation and are not claimed as my individual work.

## Evidence and results

- [Final group presentation, version 7](slides/group-final-version7.pptx), especially slides 17–23. It supersedes the older `project version5.pptx` already in the repository.
- The presentation reports a stronger simple-regression fit for the market factor than RMW for this portfolio. Numerical values are presentation results; the underlying data and analysis script are not included here, so this repository does not offer an independent rerun.
